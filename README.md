# Data Science Neural Networks

Neural Networks und PyTorch aus dem Data Science Modul meiner
Weiterbildung zur **KI-Entwicklung**.

## Inhalte

| Ordner | Beschreibung |
|---|---|
| `Uebung3302` | Dreischichtiges NN mit NumPy und scipy Sigmoid |
| `Uebung3501` | MNIST Datensatz – Visualisierung der ersten vier Ziffern |
| `Uebung3502` | MNIST – Aufteilen in Trainings- und Testdaten, Pixelskalierung |
| `Uebung3504-07` | Vollständiges NN mit manueller Backpropagation auf MNIST |
| `Uebung3601PyTorch` | PyTorch NN mit DataLoader, SGD und Genauigkeitsmessung |
| `Uebung3606Tensor` | Tensor-Grundlagen – Indexierung und Slicing |
| `Uebung3607Tensor` | Tensor-Operationen – Addition mit `torch.add` |
| `Uebung3608` | Matrixoperationen – `dot`, `mm`, `matmul`, `addmm` im Vergleich |
| `CaseStudy301` | Handy-Preisklassifikation – PyTorch NN vs KNN Vergleich |

## Highlights
- Manuelle Backpropagation mit Sigmoid-Ableitung
- Vollständiger MNIST-Trainingsprozess von Grund auf
- PyTorch NN vs KNN direkter Genauigkeitsvergleich
- Ausführliche Recherche zu PyTorch Matrixoperationen
- `torch.addmm` für lineare Transformationen

## Technologien
- **Sprache:** Python 3
- **Bibliotheken:** PyTorch, NumPy, pandas, matplotlib, scikit-learn, scipy
- **IDE:** PyCharm
